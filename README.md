# 🌈 პატარა აღმოჩენები

ქართულენოვანი საბავშვო აპლიკაცია 6 წლიდან. 45 აქტივობა ექვსი უნარისთვის, თემების ფილტრებით, ხატვით და მონტესორისგან შთაგონებული პრაქტიკული დავალებებით.

## GitHub-ზე ატვირთვა ბრაუზერიდან

1. გახსენი GitHub და შექმენი ახალი საცავი, მაგალითად `patara-aghmochenebi`.
2. ZIP ფაილი ჯერ გახსენი კომპიუტერში (Extract All).
3. საცავში აირჩიე **Add file → Upload files**.
4. გახსნილი საქაღალდიდან ატვირთე `index.html`, `README.md` და `.nojekyll` (თუ ჩანს). საქაღალდის შიგთავსი უნდა იყოს საცავის მთავარ დონეზე.
5. დააჭირე **Commit changes**.

## GitHub Pages-ზე გაშვება

1. საცავში გახსენი **Settings → Pages**.
2. **Source**: `Deploy from a branch`.
3. **Branch**: `main`; საქაღალდე: `/ (root)`.
4. დააჭირე **Save** და დაელოდე გამოქვეყნებას.
5. საიტის ბმული გამოჩნდება იმავე Pages გვერდზე.

თუ Pages ამ საცავისთვის მიუწვდომელია, შეამოწმე ანგარიშის გეგმა და საცავის ხილვადობა. Public საცავში კოდი ყველასთვის ხილულია.

## ფაილები და შენახვა

მთელი აპლიკაცია არის `index.html`-ში: HTML, CSS და JavaScript. არ სჭირდება npm, build ან API key. გასასინჯად ფაილი ბრაუზერში გახსენი.

პროგრესი და ინტერესები ინახება მხოლოდ კონკრეტული ბრაუზერის localStorage-ში. სხვა მოწყობილობაზე ან ახალ მისამართზე ავტომატურად არ გადავა. ბრაუზერის მონაცემების წაშლა ამ ჩანაწერებსაც წაშლის. ნახატები მუდმივად არ ინახება.

GitHub Pages-ის გამოცემა დამოუკიდებელია ChatGPT Site-ისგან; მას ChatGPT-ის კერძო წვდომის შეზღუდვა არ გადაჰყვება.

## მონტესორის შთაგონება

პრაქტიკული ცხოვრება, არჩევანის თავისუფლება, ხელით მუშაობა და თვითშემოწმება. ეს არის დამატებითი აქტივობები და არა სრული მონტესორის სასწავლო პროგრამა.
